# Ejemplos: Estructuras de datos fundacionales

Esta carpeta contiene ejemplos ejecutables (Python 3) que ilustran las soluciones a los problemas documentados en `docs/estructuras_fundacionales.md`.

Cómo ejecutar
- Requiere Python 3.
- Desde la raíz del repositorio:
  - python3 ejemplos/estructuras_fundacionales/top_k_frecuentes.py
  - python3 ejemplos/estructuras_fundacionales/eliminar_duplicados.py
  - python3 ejemplos/estructuras_fundacionales/pares_que_suman.py
  - python3 ejemplos/estructuras_fundacionales/agrupar_anagramas.py
  - python3 ejemplos/estructuras_fundacionales/contar_palabras.py
  - python3 ejemplos/estructuras_fundacionales/merge_intervals.py

Descripción de scripts
- top_k_frecuentes.py: encuentra los k elementos más frecuentes (rompe empates lexicográficamente).
- eliminar_duplicados.py: elimina duplicados manteniendo el orden de primera aparición.
- pares_que_suman.py: devuelve pares únicos (a,b) con a<=b que suman un objetivo.
- agrupar_anagramas.py: agrupa palabras anagramas.
- contar_palabras.py: cuenta palabras en un texto y ordena por frecuencia y lexicográficamente.
- merge_intervals.py: fusiona intervalos solapados.

No hay dependencias externas; todo usa la librería estándar.
